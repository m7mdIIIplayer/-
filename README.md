# موقع أتمتات شبكات الحاسوب

الموقع يعمل دون قاعدة بيانات ودون سيرفر.

## التشغيل
1. فك ضغط الملف.
2. افتح `index.html` بالمتصفح.

## الرفع على الإنترنت
ارفع جميع الملفات والمجلدات كما هي إلى الاستضافة، واجعل `index.html` في المجلد الرئيسي.
يمكن استخدام GitHub Pages أو Netlify أو أي استضافة ملفات ثابتة.
